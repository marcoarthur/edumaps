# Glossário

| Termo | Significado | Notas |
|---|---|---|
| **n/d** | Não disponível | Ausência de dado **nunca** significa zero (#154). |
| **IVET** | Índice de Vulnerabilidade Educacional Territorial | Índice composto por blocos; leitura com cautela em coberturas parciais. |
| **INEP** | Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira | Fonte do Censo Escolar, IDEB, SAEB. |
| **IDEB** | Índice de Desenvolvimento da Educação Básica | Indicador de qualidade da educação básica. |
| **H3** | Sistema de grade hexagonal (Uber) | Usado para agregação espacial em isócronas/área de influência. |
| **Isócrona** | Área alcançável em tempo de viagem | Calculada com Valhalla; cobertura pode ser parcial por UF. |
| **Área de influência** | Território ao redor da escola considerado na análise | Depende da resolução/grade utilizada. |
| **LGPD** | Lei Geral de Proteção de Dados Pessoais (Lei 13.709/2018) | Dados sensíveis devem ser tratados com cuidado. |
| **PII** | Informação Pessoal Identificável | Ex.: nomes, contatos, dados individuais. |
| **SIOPE** | Sistema de Informações sobre Orçamentos Públicos em Educação | Dados financeiros/orçamentários; agregado da Secretaria pode diferir da escola (#70/#91). |
