# Fontes de dados

> **Para quem:** Administrador  
> **Tempo de leitura:** ~4 min

## Em 30 segundos
Gerenciamento e acompanhamento das fontes de dados utilizadas pelo EduMaps.

## Passo a passo
1. **Onde ir:** Administração → Fontes de dados
2. **Verificar** status de cada fonte
3. **Acompanhar** última atualização
4. **Investigar** falhas quando houver

## Limitações conhecidas
- Algumas fontes têm atualizações periódicas fora do controle direto.
- Falhas podem ser temporárias.
- **Acidentes da ANTT:** a fonte só informa a rodovia e o quilômetro. O
  município de cada acidente sai dos marcos quilométricos da ANTT. A nota da
  carga mostra quantos acidentes ficaram sem município e por quê (sem marco no
  trecho, trecho fora do padrão, ponto fora do mapa municipal). Esses acidentes
  não entram na contagem de nenhuma escola. Se o número subir de uma carga para
  outra, confira se a camada de marcos foi atualizada. Os acidentes cobrem
  **só as rodovias federais concedidas**.

## Privacidade
Respeitar políticas das fontes oficiais.
