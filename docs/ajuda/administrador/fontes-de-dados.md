# Fontes de dados

> **Para quem:** Administrador  
> **Tempo de leitura:** ~4 min

## Em 30 segundos
Gerenciamento e acompanhamento das fontes de dados utilizadas pelo EduMaps.

## Passo a passo
1. **Onde ir:** Administração → Fontes de dados
2. **Verificar** status de cada fonte
3. **Acompanhar** última atualização
4. **Investigar** falhas quando houver

## Limitações conhecidas
- Algumas fontes têm atualizações periódicas fora do controle direto.
- Falhas podem ser temporárias.

## Privacidade
Respeitar políticas das fontes oficiais.
