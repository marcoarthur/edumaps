# Buscar escola (público)

> **Para quem:** Família/responsável/cidadão  
> **Tempo de leitura:** ~3 min

## Em 30 segundos
Qualquer pessoa pode buscar escolas públicas pelo nome, município ou outros filtros na busca pública do EduMaps.

## Passo a passo
1. **Onde ir:** Página inicial/busca pública do EduMaps
2. **Digite** o nome da escola, município ou termo desejado
3. **Selecione** a escola nos resultados
4. **Abra** o painel público da escola

## Entendendo os números
- **n/d** = não disponível (#154). Ausência nunca é zero.
- Nem todas as informações estão visíveis na versão pública.

## Limitações conhecidas
- Algumas informações só aparecem para usuários autenticados com perfil adequado.
- Cobertura varia por fonte.

## Privacidade
- A busca pública **não** exige login.
- São exibidas apenas informações **públicas/agregadas**.

## Perguntas frequentes
- **Preciso criar conta para buscar?** Não, a busca é pública.
- **Vejo todos os dados?** Apenas o que é público por design (LGPD).
