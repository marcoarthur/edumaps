# Comparar redes

> **Para quem:** Comunidade interessada em comparar contextos  
> **Tempo de leitura:** ~3 min

## Em 30 segundos
Em alguns contextos é possível comparar informações entre escolas/redes, sempre com dados agregados e públicos.

## Passo a passo
1. **Onde ir:** Funcionalidade de comparação (quando disponível)
2. **Selecione** as escolas/redes desejadas
3. **Analise** os indicadores comparados
4. **Observe** anos e "n/d"

## Entendendo os números
- **n/d** = não disponível (#154). Ausência nunca é zero.
- Comparações só fazem sentido com **mesmo ano/referência** quando possível.

## Limitações conhecidas
- Funcionalidade pode estar em evolução.
- Alguns indicadores não são comparáveis entre recortes.

## Privacidade
Somente dados públicos/agregados.

## Perguntas frequentes
- **Por que não consigo comparar?** Pode não estar disponível para aquele contexto.
