# Problemas comuns (gestor)

> **Para quem:** Gestor  
> **Tempo de leitura:** ~4 min

## Checklist rápido
| Sintoma | Possível causa | Ação sugerida |
|---|---|---|
| **Vejo "n/d"** | Dado não disponível para ano/recorte | Verifique ano de referência. Ausência **nunca** é zero (#154). |
| **Bloco vazio** | Cobertura parcial da fonte | Pode não haver dados para esta escola/UF. |
| **Financeiro diferente do esperado** | Valor agregado da Secretaria | Verifique se é agregado (não desagregado por unidade) (#70/#91). |
| **QR não gera** | Permissão/configuração | Verifique permissão ou se a pesquisa está ativa. |
| **Área de influência vazia/incompleta** | Cobertura territorial | Pode ser limitação de mapeamento ou cobertura parcial. |

## Limitações conhecidas
Muitos casos são limitações de cobertura, não erros da plataforma.
