# Clusters de escolas

> Módulo: `analise` · Status: 🟢 ativo · Público: pesquisador, gestor, investidor

## Resumo

A plataforma agrupa escolas com características e contextos parecidos,
produzindo uma leitura exploratória da rede por semelhança (inclusive
geográfica).

## Para quem

Pesquisadores que buscam padrões, gestores que planejam por grupos de escolas e
investidores que segmentam redes.

## O que o sistema permite

- Sistema pode agrupar escolas por atributos e geografia.
- Sistema pode descrever os grupos em linguagem natural.
- Sistema pode apoiar decisões de rede a partir dos agrupamentos.

## Valor

Revela grupos de escolas que fazem sentido tratar juntos, evitando políticas
genéricas.
