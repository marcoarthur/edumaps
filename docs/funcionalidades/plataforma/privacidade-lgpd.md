# Privacidade e LGPD

> Módulo: `plataforma` · Status: 🟢 ativo · Público: gestor, comunidade, pesquisador

## Resumo

A plataforma trata dados pessoais com cuidado: separa o que é público (Censo) do
que é sensível (contatos, documentos, respostas), restringe o acesso e evita
expor identificadores.

## Para quem

Gestores e comunidade (titulares dos dados) e a própria plataforma.

## O que o sistema permite

- Sistema pode restringir dados pessoais da escola ao gestor autenticado daquela
  escola.
- Sistema pode mascarar identificadores sensíveis (ex.: CPF) nas respostas.
- Sistema pode anonimizar a participação da comunidade (resposta por link, sem
  conta, com bloqueio leve por dispositivo).
- Sistema pode guardar documentos em área controlada, sem expô-los publicamente.

## Valor

Confiança e conformidade: a gestão ganha ferramentas sem transformar a escola em
um repositório exposto de dados pessoais.
