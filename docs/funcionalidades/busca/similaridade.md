# Escolas similares

> Módulo: `busca` · Status: 🟢 ativo · Público: gestor, pesquisador, investidor

## Resumo

A plataforma identifica escolas semelhantes a uma escola de referência,
permitindo comparação entre pares e troca de experiências entre unidades com
contextos parecidos.

## Para quem

Gestores que querem referências próximas, pesquisadores que estudam grupos de
escolas e investidores que avaliam redes.

## O que o sistema permite

- Sistema pode, a partir de uma escola, sugerir escolas semelhantes por perfil e
  contexto: da mesma cidade, com ao menos uma etapa de ensino em comum (uma
  creche não é sugerida para uma escola de ensino fundamental) e com as notas
  do painel mais próximas, explicando esse critério na tela.
- Sistema compara as notas **nota a nota, no mesmo patamar**: uma escola com
  o mesmo perfil de notas, mas bem acima ou bem abaixo, não é sugerida como
  parecida.
- Sistema mostra **o quanto cada sugestão se parece**: a distância em pontos
  e as notas da escola sugerida ao lado das notas da escola de referência.
- Sistema pode levar a comparação para o painel da escola e para os agrupamentos
  (clusters).
- Sistema mantém a comparação do painel da escola em dia sozinho, todo dia,
  quando as notas das escolas mudam (Censo novo), e tira da comparação as
  escolas que deixaram de existir.
- Sistema não compara uma escola a que falta dado como se o dado fosse zero:
  ela fica fora da comparação, e a tela diz que falta dado.

## Valor

A comparação com pares ajuda a escola a entender seu desempenho relativo e a
buscar práticas que funcionam em contextos similares.
