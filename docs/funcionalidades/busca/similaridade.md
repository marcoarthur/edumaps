# Escolas similares

> Módulo: `busca` · Status: 🟢 ativo · Público: gestor, pesquisador, investidor

## Resumo

A plataforma identifica escolas semelhantes a uma escola de referência,
permitindo comparação entre pares e troca de experiências entre unidades com
contextos parecidos.

## Para quem

Gestores que querem referências próximas, pesquisadores que estudam grupos de
escolas e investidores que avaliam redes.

## O que o sistema permite

- Sistema pode, a partir de uma escola, sugerir escolas semelhantes por perfil e
  contexto.
- Sistema pode levar a comparação para o painel da escola e para os agrupamentos
  (clusters).

## Valor

A comparação com pares ajuda a escola a entender seu desempenho relativo e a
buscar práticas que funcionam em contextos similares.
