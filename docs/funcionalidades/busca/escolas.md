# Busca de escolas

> Módulo: `busca` · Status: 🟢 ativo · Público: comunidade, gestor, pesquisador, investidor

## Resumo

A plataforma permite localizar qualquer escola pública brasileira pelo nome ou
município e abrir um retrato inicial dela, com contato, localização e atalhos
para os painéis analíticos e de gestão.

## Para quem

Qualquer pessoa que precise encontrar uma escola: famílias, gestores,
pesquisadores e órgãos públicos.

## O que o sistema permite

- Sistema pode buscar escolas por nome ou município, com paginação.
- Sistema pode exibir, para cada escola, contato, endereço, mapa e WhatsApp.
- Sistema pode encaminhar da escola encontrada para o painel da escola e para a
  área do gestor daquela unidade.

## Valor

Ponto de entrada da plataforma: transforma um interesse ("a escola X") em acesso
imediato a dados e ferramentas.
