# Painel do gestor

> Módulo: `gestor` · Status: 🟢 ativo · Público: gestor

## Resumo

É a central de gestão da escola: reúne o raio-x da unidade e dá acesso aos
módulos de gestão (pesquisas, reuniões, contatos, inventário e relações
institucionais).

## Para quem

Gestores escolares.

## O que o sistema permite

- Sistema pode apresentar o retrato da escola e, a partir dele, abrir os módulos
  de gestão.
- Sistema pode servir de "casa" do gestor dentro da plataforma.

## Valor

Um único ponto de partida para o trabalho de gestão, com o contexto da escola
sempre à mão.
